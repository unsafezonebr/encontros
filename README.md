# UnsafeZone — Encontros

O UnsafeZone é um encontro mensal de segurança ofensiva, em português, que acontece em Camaçari - BA.

Este repositório reúne os materiais das apresentações de cada encontro: slides, PDFs, vídeos e demais anexos.

## Organização

Cada encontro tem sua própria pasta, no formato `NN-AAAA-MM-DD` (número do encontro e data). Dentro dela, cada palestrante tem uma subpasta com seu material. Ex. do primeiro encontro:

```
01-2026-09-30/
├── 01-Introducao.pdf
├── alacerda/
├── prsantos/
└── yueslly/
```
